El problema tiene dos lados

El que atiende

No sabe si el cliente que dijo “voy” va a llegar. Se queda esperando, deja de atender a otros o pierde la silla.

El que va

No sabe si lo pueden atender. Pierde el viaje, encuentra cerrado o llega y ya están ocupados.

Cómo funciona

  1. Se aparta el turno

    El profesional escribe “Ana a las 4”, o el cliente lo pide por WhatsApp.

  2. Se confirma

    El cliente confirma con un botón. Si no responde, el asistente se lo recuerda.

  3. Se avisa antes

    Antes de la hora le pregunta cómo va. Si la cita es para otro día, se la recuerda la tarde anterior.

  4. Si no responde, se libera

    El espacio queda libre y el profesional se entera de una vez, para atender a otra persona.

Preguntas

¿Mis clientes o mi equipo tienen que instalar algo?

No. Todo pasa por WhatsApp. No hay app, usuario ni contraseña.

¿Qué pasa si el cliente no responde?

El asistente se lo recuerda. Si sigue sin responder, libera el espacio y te avisa. Si prefieres guardarle el turno, respondes “mantener”.

¿Le escribe a gente que nunca me ha escrito?

No. Si el cliente nunca le ha escrito a tu negocio, el asistente le da al profesional un mensaje con un enlace para que se lo reenvíe. Desde que el cliente responde, ya le puede escribir, y puede dejar de recibir mensajes cuando quiera escribiendo SALIR.

¿La inteligencia artificial decide sobre mis turnos?

No. Solo se usa para entender lo que la gente escribe o dice. Cuándo se confirma, se recuerda o se libera un turno lo deciden reglas fijas.

¿Qué pasa con los datos de mis clientes?

Se usan solo para manejar los turnos. No se usan para publicidad ni se venden. El detalle está en la política de datos.
